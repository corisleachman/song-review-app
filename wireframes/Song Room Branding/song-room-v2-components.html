Display vs. UI Font Rule

Impact is a display typeface — it was designed for large-scale use and degrades at small sizes, reading as dense and aggressive inside confined pill or badge shapes. DM Sans 600 uppercase takes over for all functional UI labelling below ~14px. This creates a clear hierarchy: Impact for authority, DM Sans for legibility.

Context Font Weight Case
Hero headings, auth headings Impact — Uppercase
Section headers, panel labels, nav items Impact — Uppercase
Song titles (card + hero) Impact — Uppercase
CTA buttons, primary actions Impact — Uppercase
Pills, badges, status tags, filter chips, count chips DM Sans 600 Uppercase · ls 0.06–0.08em
Secondary UI labels (eyebrows, sort labels, author names) DM Sans 600 Uppercase · ls 0.06–0.1em
Body copy, descriptions, comments DM Sans 400 Sentence
Timestamps, metadata, version IDs Georgia italic italic Sentence

Corner Radius Rule

Border-radius is 0 everywhere by default. The editorial identity of The Song Room depends on this being total — a single rounded exception reads as an oversight, not a decision. This applies to comment bubbles, inputs, buttons, cards, modals, panels, and all containers without exception.

Element Radius Reason
Buttons, inputs, cards, modals, panels 0 The rule. No exceptions.
Comment bubbles 0 Not a consumer chat app. Rounded bubbles import the wrong associations (iMessage, WhatsApp). Differentiate own/other messages via surface colour and border weight instead.
Stage pills, status badges, count chips 0 Inline labels use borders and surface colour for identity — not shape. Sharp badges read as editorial tags, not UI affordances.
Avatar initials 50% (circle) Permitted exception. The circle signals "person" — a functional convention that aids identity recognition at a glance. Not decorative.
Waveform marker dots 50% (circle) Permitted exception. Circular markers on a timeline are a spatial convention — they indicate a point, not a region. Squaring them would create confusion with the waveform bar itself.
