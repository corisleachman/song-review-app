Implementation notes
Bottom dock
  • Fixed to bottom of phone on every page — position: sticky or layout flex child
  • Always renders; mini player slot conditionally shown
  • 60px height — comfortable tap target, doesn't crowd content
  • Subtle dark background + border-top separates from content

Mini player — dashboard only
  • Appears when currentSong !== null
  • Shows: album art, song title, version + elapsed time
  • Play/pause button controls playback without navigating
  • Tap anywhere else on mini player → navigate to song page
  • Disappears on song page (full player already visible)

Home icon
  • Always present, always navigates to /dashboard
  • Solves the scroll trap — reachable from any depth
  • Label "Home" beneath for first-time clarity

No back button removed
  • Song page keeps the "← All songs" link in the header
  • Dock home is an additional escape, not a replacement
